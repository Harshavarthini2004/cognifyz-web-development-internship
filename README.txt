COGNIFYZ IT SOLUTIONS – WEB DEVELOPMENT INTERNSHIP
PROJECT README

Project Name:
Web Development Internship – Level 1 and Level 2

Selected Levels:
Level 1 and Level 2

Project Overview:
This project contains the completed tasks for Level 1 and Level 2 of the
Cognifyz Web Development Internship Task List. Each task is maintained in
a separate folder with its source code, images, JavaScript files where
required, and output screenshots.

LEVEL 1

Task 1 – Arivu Book House
Technology: HTML and CSS

Features:
- Simple webpage with heading and paragraph
- Bookstore image
- Three-link navigation menu: Home, About, Contact
- Basic contact form with one text input and Submit button
- Separate Home, About and Contact pages
- CSS styling and responsive behavior

Task 2 – Aarogya Fitness Studio
Technology: HTML, CSS and JavaScript

Features:
- Button color change when clicked
- Time-based greeting using JavaScript alert
- Simple calculator that adds two numbers
- Interactive fitness-themed interface

LEVEL 2

Task 1 – Urban Coffee
Technology: Bulma, Bootstrap, HTML, CSS and JavaScript

Features:
- Responsive card using Bulma
- Card contains image, title and description
- Responsive grid using Bootstrap
- Three menu-highlight columns
- Interactive "View Details" button
- Mobile Bulma navigation menu on the home page
- Separate Home and Menu pages

Task 2 – Rohan Photography
Technology: HTML, CSS and JavaScript

Features:
- Responsive webpage using CSS media queries
- Desktop navigation menu
- Mobile hamburger navigation
- Responsive gallery layout
- Separate Home, Gallery, About and Contact pages
- Responsive contact form
- JavaScript controls the mobile menu

OUTPUT:
The output folders contain screenshots demonstrating the completed
web pages and interactive features.

HOW TO RUN:
1. Extract the ZIP file.
2. Open the required task folder.
3. Open index.html in a web browser.
4. For multi-page tasks, use the navigation links to open the other
   HTML pages.
5. For Level 2 Task 1, an internet connection may be required because
   Bulma and Bootstrap are loaded through CDN links.
